# 🚀 React Project (Portfolio / Dashboard App)

A simple React project for managing and displaying projects with a clean UI, including search and project details pages.

---

## 📦 Features

- Add new projects (title + description)
- Search/filter projects
- Project details page using React Router
- Clean responsive UI cards
- Basic dashboard layout

---

## 🛠️ Tech Stack

- React
- React Router DOM
- JavaScript (ES6+)
- CSS (custom styling)
